# 🔐 Password Strength Checker

## 📌 Project Overview
The Password Strength Checker is a Python application that evaluates password strength based on essential security requirements. It identifies missing conditions and provides suggestions to create stronger passwords.

## ✨ Features
- Checks whether the password contains at least 8 characters.
- Verifies uppercase letters (A-Z).
- Verifies lowercase letters (a-z).
- Checks for numbers (0-9).
- Checks for special characters.
- Displays password improvement suggestions.
- Displays a success message for strong passwords.

## 🛠️ Technologies Used
- Python 3

## ⚙️ Password Requirements
A strong password must contain:
1. At least 8 characters.
2. One uppercase letter.
3. One lowercase letter.
4. One number.
5. One special character.

## ▶️ How to Run the Project

1. Clone the repository.
2. Open the project folder.
3. Run the following command:

```bash
python password_checker.py
```
